=================
Bulk Data Service
=================

The `Bulk Data Service <https://bulk-data.iatistandard.org>`_ runs on a continuous basis to maintain a copy of all datasets registered with IATI. The Bulk Data Service makes available a cached copy of each IATI dataset to allow access during temporary server outages, and in addition provides a ZIP file that allows all IATI datasets to be downloaded. 

The `Bulk Data Service API specification <../api-docs/bulk-data-service-api/>`_ explains what information about the download status of each IATI dataset is available.
